
## A custom vim-like Editor

On top of my head, vim has a regex engine.
And an architecture which can support various configurable
bindings.

So, my goal is if I get rid of above two, I would have a 
easier time to develop my own editor.

## Development so far

So, I used libncurses, just because It was already used for
defconfig pages, won't be hard to build a editor.

I got to a point where I can write text into a buffer.
I wanted to use arrow keys to try to make editing possible.
But there was something wrong.

## Why Editor

Then, I was wondering why I started this.
I wanted to build an OS. And decided to start with userspace.

I have no though to that decision.
If I want to implement something in kernel space. It totally 
not possible. Because libncurses uses syscalls. Even in userspace
also it difficult because I need all generic syscalls, which 
would take ages.

This OS project would takes years. It does not really make
sense to do this. And also its not that interesting. It sort of
feels like html and css.

Maybe at a certain stage, I'll consider it.
